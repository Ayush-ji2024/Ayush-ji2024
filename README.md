## 🚀 Featured Projects

### 🌾 [Krishi Mitra](https://github.com/Ayush-ji2024/krishi-mitra) — crop advisor for Indian farmers

<a href="https://github.com/Ayush-ji2024/krishi-mitra">
  <img src="https://raw.githubusercontent.com/Ayush-ji2024/krishi-mitra/main/docs/screenshots/home.png" alt="Krishi Mitra home screen" width="720"/>
</a>

Soil type from a photo, live local weather from a village name, and crop suggestions that respect the soil — in Hindi and English.

- 🔍 **Audited the dataset:** found 57% duplicate images and **100% train–test leakage**; rebuilt a clean, stratified split
- 🧠 **Soil classifier:** MobileNetV2 transfer learning — **91.1% test accuracy, 0.91 macro-F1**
- 🌱 **Crop recommender:** benchmarked 3 models with 5-fold CV; Random Forest — **99.3% accuracy, 100% top-3**
- ⚙️ **FastAPI backend** with input validation, FAO ECOCROP soil-aware ranking, Open-Meteo weather and **21 tests**
- 📱 **Mobile-first React frontend** — step-by-step advisor, Hindi / English

`PyTorch` `scikit-learn` `FastAPI` `React` `Vite` `pytest`

### 🏏 Kurukshetra — live scores for our college's annual games *(team project, 2026)*

A mobile-first website for the 31 events of the annual games at RRSDCE Begusarai: live scores, results, rules and notifications, open to everyone without login.

- ⚡ **Live scoring:** cricket ball-by-ball and badminton point-by-point; the server counts the score from every ball / point, with undo
- 🔐 **Secure admin & scorer login:** PBKDF2 password hashing, HttpOnly sessions, CSRF protection and login rate limiting
- 🔔 **Notifications** with photo / PDF attachments (Workers KV); the file type is checked from the file's bytes, not its name
- 📄 **Rule book** with downloadable PDFs, and match results shared as images (Canvas + Web Share API)
- ☁️ Runs on **Cloudflare's free plan**: Workers + Hono API and a D1 (SQLite) database with 14 migrations
- 👥 Team of 3 — I built the **backend and deployment**; Anand Kumar (design), Rishikesh Kumar (security)

`React` `TypeScript` `Tailwind CSS` `Cloudflare Workers` `Hono` `D1 / SQLite`
